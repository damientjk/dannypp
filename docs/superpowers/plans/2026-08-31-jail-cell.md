# Jail Cell Implementation Plan (executed 2026-08-31)

**Goal:** Convert the Database room (top-right) into the world's Jail Cell — bars with one cell door across the front, toilet + toilet paper top-left, two bunk beds top-right — and teleport any agent straight into it when it is caught reaching for another owner's room ("touches the wrong file").

The user hand-picked the art into `jail/` at the repo root; all five crops byte-match files in `18_Jail_Singles_32x32` (toilet `_44`, paper `_48`, bed `_38`, bars `_19`, barred door `_20`), so the decor pipeline references the pack directly, same as every other room.

**What changed:**

- `scripts/room_layout.py` — `DECOR["database"]` is now the jail set: toilet (0,0), paper (1,0), beds (7,0)/(8,0), and a 9-segment bars row at interior row 5 (64px tall, reaching down over the front wall's top face), with the door segment on the `DOOR_COL` column so it lines up with the wall frame's doorway. `DESKS["database"]` and the incense-burner `EQUIPMENT` binding are gone — nobody works in a jail. Floor/wall textures kept (user marked only furniture + bars).
- `src/world/resources.ts` — the `database` entry keeps its id, zone, owner (user-b) and `requiresPermission` (that's what keeps roamers out and a task naming it deniable), but `displayName` is now "Jail" and `deskIds` is empty. New `JAIL_ROOM_ID = "database"`.
- `src/world/types.ts` — `BehaviorMode` + `"jailed"`, `LogCategory` + `"jailed"`.
- `src/world/agentSim.ts` — `jailAgent()` (teleport to the jail zone's centre, mode "jailed"), `releaseAgent()` (teleport back to the common spawn, roaming), `jailRoamAdapter` (jailed agents pace the cell: jail-zone tiles minus the bars row), `advanceBehavior` treats "jailed" as wandering with that adapter.
- `src/world/WorldView.tsx` — in the task-visit orchestration, a deny on a room owned by someone other than the agent's owner no longer queues a request: the agent is jailed on the spot, with a BLOCKED + JAILED pair in the security log. When the offending run ends (the existing `!isBusy` branch), the agent is released. Roster pill shows "in jail"; JAILED badge label added.
- `src/styles.css` — `jailed` added to the deny/denied badge and log-row color groups (same red).
- Regenerated `map.json` (desk-database spawn points gone; collision/geometry otherwise identical) and `room-decor.json` + `decor/database/*`; deleted the orphaned Japanese decor files and the incense spritesheet (all in git history).

**Deliberately not done:** no collision change (the cell door tile stays walkable — jailed agents are confined by the jailed-roam adapter, and ordinary roamers never enter gated zones); jail floor/wall textures unchanged; a deny on the agent's own owner's room still goes through the request/grant flow — jailing there would kill the keycard demo loop.

## Fix round (2026-08-31, user review): blend the bars, real doorway walls, bed gap, no accent rectangles

User feedback with two reference screenshots (the pack's jail cells, and its gym design with the interior partition walls circled): the old thin front face clashed with the bars, the top-row doorways read as slots, the beds sat flush, and the zone-accent rectangles sliced across doorways, the bars, and the beds.

- Top-row front walls are now partition-style (the circled reference walls): NAVY | WHITE | NAVY top face plus a flat wall face (`side_wall_color` at the gradient's bottom shade) one tile deep, doorway cut through the full depth with navy jambs. Bottom-row outer walls keep the near-absent 12px face.
- The jail's front is all face, no white band — the bars decor stands on it like the pack's own cells' kerb, merging with the side walls at both ends; its wall has no doorway at all (the barred cell door is the way in, and agents teleport anyway).
- `bed-left` moved to col 6.5 — a half-tile gap between the beds (fractional cols are fine: the generator multiplies by TILE).
- The accent rectangles are gone for every room (explicit user request, superseding a door-gapped version built mid-round); ownership stays legible through the label tint (blue yours / red another owner's). The label plate's accent-related bottom-clamp went with it.

## Fix round 2 (2026-08-31, user review): back-wall-height front walls, butted junctions, bars on the kerb

## Fix round 3 (2026-08-31, user review): front wall in front, pillars for the bars, no kerb

Two reference images from the user (the pack's castle-wall piece and its own jail design) settled the junction direction:

- Top-row front walls now span the room's FULL width, and everything vertical — side bands, side top-faces, and their outlines — terminates on the front wall's *back* edge in a T-junction ("the wall connects to the back of the front wall, not the front wall connecting to the back").
